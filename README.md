## Email-форма

Форма отправляет email во внешний Cloudflare Worker, а Worker — транзакционное письмо через Resend. Ссылка на Google Drive и текст письма зафиксированы на сервере: браузер не может подменить содержание или использовать endpoint как открытый почтовый ретранслятор. Оплата пока не подключена.

Защита состоит из точной проверки Origin, серверной проверки Cloudflare Turnstile, скрытого honeypot-поля, ограничений размера запроса и двух независимых лимитов частоты (по источнику и адресу получателя). Секреты Resend и Turnstile доступны только Worker. При отсутствии публичной конфигурации GitHub Pages форма показывает нейтральный статус подготовки и не отправляет запросы.

## Локальная работа

Node.js 22.13+ (на Windows проверяется Node 22), npm:

```sh
npm ci
npm run dev
npm run build
npm run test:worker
npx tsc --noEmit
npx oxlint app/page.tsx app/test-email.tsx app/layout.tsx vite.config.ts
```

Vinext/Vite собирает локальную версию в dist/client. npm run preview запускает локальный просмотр. app/page.tsx содержит тексты, app/globals.css — оформление, app/test-email.tsx — автономную форму.

## Публикация

.github/workflows/pages.yml запускается при push в main и вручную. GitHub Actions устанавливает Next 16, убирает три локальных CSS-импорта в копии CI, выполняет статический экспорт с basePath /dmitry-crisis-course и публикует out через GitHub Pages. Локальный npm run build проверяет Vinext; Pages-сборку проверяет отдельная задача build в Actions.

Для активации почты нужны:

1. Верифицированный домен и адрес отправителя в Resend; адрес записывается в `RESEND_FROM` в `worker/wrangler.jsonc`.
2. Turnstile widget с разрешённым hostname `lolliagodx.github.io`.
3. GitHub Actions secrets: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `RESEND_API_KEY`, `TURNSTILE_SECRET_KEY`.
4. Ручной запуск workflow `Deploy course email Worker`.
5. GitHub Actions variables: `COURSE_DELIVERY_API_URL` (полный URL `/course-access`) и `TURNSTILE_SITE_KEY`, затем повторный запуск Pages workflow.

Секреты нельзя добавлять в исходный код, `.env.example` или публичные GitHub variables. Worker разворачивается отдельно вручную, чтобы Pages-публикация не падала до появления внешних учётных данных.
