# dmitry-crisis-course

Адаптивный рабочий макет лендинга образовательной и практической программы самопомощи Дмитрия. Исходники подготовлены для GitHub Pages и статического хостинга.

## Запуск

Нужны Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Открыть адрес, показанный в терминале (обычно http://localhost:3000).

```sh
npm run build
```

Статический результат находится в `dist/client`. Для просмотра сборки запустите `npm run preview`.

## GitHub Pages

В репозитории есть `.github/workflows/pages.yml`: запуск вручную через Actions → Deploy GitHub Pages → Run workflow. Сборка учитывает адрес `/dmitry-crisis-course/`. Публикация запускается вручную, чтобы черновик не выходил автоматически при каждом изменении.

1. Убедитесь, что тариф GitHub поддерживает Pages для выбранной видимости репозитория. Приватный репозиторий на бесплатном тарифе может не поддерживать Pages. Сделать код публичным — отдельное решение владельца.
2. Settings → Pages → Build and deployment → Source: GitHub Actions.
3. Запустите workflow. Адрес опубликованного сайта появится в результате deploy.

Ожидаемый адрес после успешного включения Pages: `https://lolliagodx.github.io/dmitry-crisis-course/`. Наличие этой строки не означает, что Pages уже опубликован.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

Для ручной сборки под Pages в PowerShell:

```powershell
$env:GITHUB_PAGES = 'true'
npm run build
Remove-Item Env:GITHUB_PAGES
```

Для другого имени репозитория измените `basePath` в `next.config.ts`. Для корневого домена собирайте без `GITHUB_PAGES`.

## Где редактировать

- `app/page.tsx`: тексты, блоки, социальные кнопки и программа.
- `app/globals.css`: палитра, сетки и мобильные стили.
- `app/layout.tsx`: заголовок, описание, язык и запрет индексации черновика.
- `public/favicon.svg`: временный знак.
- `docs/design-notes.md`: решения по референсам и содержание из интервью.

## Состояние макета

Работают якорное меню, переход к участию, раскрытие тем, ссылка наверх и клавиатурная навигация. Соцсети и оплата отключены намеренно и подписаны. Форм, платежей, аналитики и сбора контактов нет. Фотография автора — явный placeholder, чужой портрет не используется.

Название курса, заголовки и направления — черновик. Основные описания заключены в квадратные скобки; сроки, цена и юридические документы не выдуманы. Перед запуском заменить заглушки, утвердить программу, подтвердить биографию и компетенции автора, добавить настоящие контакты, документы и платёжный сценарий. Затем обновить метаданные и разрешить индексацию.

Позиционирование: образовательная программа самопомощи, без диагностики, лечения и психотерапии. Нет гарантий исцеления, дохода, отзывов или неподтверждённых квалификаций. Исходное интервью и личные подробности не включены в репозиторий.

## Технологии

React 19, TypeScript, Vinext/Vite, CSS, Lucide. Статический экспорт без серверной базы данных. Базовый шаблон Sites и установленный каталог компонентов сохранены. Необязательный WebMCP `navigate_course_section` повторяет переход по разделам и ничего не отправляет; в неподдерживаемом браузере не активируется.

На Windows рекомендуем Node.js 22: на установленном Node.js 24.19 наблюдался сбой завершения процесса сборки Vinext. Сборка на Node.js 22 прошла успешно.


## Проверки

Статическая сборка успешно завершена на Node.js 22; TypeScript и проверка кода в app/scripts прошли. Полный lint каталога шаблонных компонентов сообщает замечания в неиспользуемых компонентах и hooks; они не исправлялись в рамках макета. WebMCP проверен на допустимом и недопустимом разделе. Визуальный макет просмотрен и одобрен пользователем; автоматическое браузерное тестирование разных разрешений не проводилось.
