# Новая точка отсчета

Лендинг образовательной программы самопомощи. Сайт: https://lolliagodx.github.io/dmitry-crisis-course/.

## Содержание и дизайн

Сохранены чёрно-золотой дизайн, рамка автора и порядок разделов: первый экран → автор → подход → программа → участие → футер. Раздел автора намеренно пуст, включая заголовки и подписи.

Тексты обновлены 16 сентября 2026 по двум документам пользователя: «Курс супер финал (1).docx» и «Курс_сценарий_полныйю.docx». Десять учебных блоков сгруппированы в четыре существующих аккордеона:

1. Точка А и цели — блоки 0 и 1.1.
2. Здоровье, энергия и эмоции — блоки 1.2 и 1.3.
3. Отношение к себе и близким — блоки 2.1, 2.2 и 2.3.
4. Реализация, финансы и интеграция — блоки 3, 4 и 5.

Исходные документы и личные истории не включены в Git. Цена, сроки, квалификации и гарантии результата не добавлены. Запрет индексации сохранён.

## Email-форма

Кнопка «Покупка скоро откроется» раскрывает поле email. Браузер проверяет обязательность и формат. Отправка формы только отменяет стандартное действие и показывает «Тестовый режим: письмо не отправляется».

Нет fetch, POST, переходов, сохранения адреса, аналитики или обращения к backend. Поле не имеет name, чтобы даже стандартная отправка не включала email. Почтовый middleware отключён в Vite: dev и публичная версия работают одинаково, независимо от переменных окружения. Старые server/test-email.mjs и scripts/test-email.mjs сохранены как неиспользуемый исторический код. Не запускайте их для проверки интерфейса. Оплата не подключена; секреты и .env не изменялись.

## Локальная работа

Node.js 22.13+ (на Windows проверяется Node 22), npm:

```sh
npm ci
npm run dev
npm run build
npx tsc --noEmit
npx oxlint app/page.tsx app/test-email.tsx app/layout.tsx vite.config.ts
```

Vinext/Vite собирает локальную версию в dist/client. npm run preview запускает локальный просмотр. app/page.tsx содержит тексты, app/globals.css — оформление, app/test-email.tsx — автономную форму.

## Публикация

.github/workflows/pages.yml запускается при push в main и вручную. GitHub Actions устанавливает Next 16, убирает три локальных CSS-импорта в копии CI, выполняет статический экспорт с basePath /dmitry-crisis-course и публикует out через GitHub Pages. Локальный npm run build проверяет Vinext; Pages-сборку проверяет отдельная задача build в Actions.
